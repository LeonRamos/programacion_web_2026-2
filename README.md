# Programación Web (Clave: AEB-1055) - Semestre 2026-2

Bienvenido al repositorio oficial de la asignatura **Programación Web** del Tecnológico Nacional de México (TecNM). 

El objetivo de esta materia es desarrollar competencias profesionales en el diseño, desarrollo y despliegue de **aplicaciones web dinámicas e integrales (Full Stack)**, abarcando desde la capa de cliente hasta el backend y servicios en la nube.

---

## Objetivo General
Desarrollar aplicaciones web dinámicas del lado del cliente y del servidor, considerando la conectividad a orígenes de datos, la interconectividad entre aplicaciones y el cómputo en la nube.

---

## Temario y Estructura del Curso

| Unidad | Tema | Proyecto / Entregable Práctico |
| :--- | :--- | :--- |
| **1. Introducción a las Aplicaciones Web** | Evolución, arquitecturas (Client-Server, MVC), tecnologías y planificación. | Documento de arquitectura & Diagrama C4 del Portafolio. |
| **2. HTML, XML y CSS** | Estructura semántica, maquetación, Formularios, Selectores y Modelo de Caja. | Maquetación responsiva del sitio personal / Catálogo. |
| **3. Programación del lado del Cliente** | JavaScript (ES6+), manipulación del DOM, eventos y Frameworks (React/Vue). | Interfaz interactiva, carrito de compras / consumo de APIs. |
| **4. Programación del lado del Servidor** | Servidores HTTP, APIs REST, tratamiento de formularios, POO y manipulación de DB. | API RESTful con autenticación y conexión a Base de Datos. |
| **5. Cómputo en la Nube y Servicios** | Microservicios, estándares, seguridad, autenticación (JWT/OAuth) y despliegue. | Despliegue continuo (CI/CD) en Vercel/Render/AWS. |

---

## Tech Stack Recomendado

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), TailwindCSS / Bootstrap, React.js / Vue.js.
- **Backend:** Node.js (Express) *o* Python (FastAPI/Django) *o* PHP (Laravel).
- **Base de Datos:** PostgreSQL / MySQL / MongoDB.
- **Cloud & Deployment:** Render, Vercel, Supabase / Firebase, GitHub Actions.

## Flujo de Trabajo para Estudiantes (Workflow)

Para mantener el control del portafolio individual, se sugiere que cada estudiante trabaje mediante **Forks y Pull Requests**:

1. **Realizar un Fork** de este repositorio a su cuenta personal de GitHub.
2. Clonar el repositorio forkeado localmente:
   ```bash
   git clone [https://github.com/TU_USUARIO/programacion_web_2026-2.git](https://github.com/TU_USUARIO/programacion_web_2026-2.git)
   ```
3. Crear una rama por cada unidad o práctica:
   ```bash
   git checkout -b feature/unidad-02-html-css
   ```
4. Subir avances y solicitar un **Pull Request (PR)** para revisión y retroalimentación.

##  Portafolio Final Entregable

Al finalizar el curso, la carpeta `/proyecto-integrador` contendrá una **Aplicación Web Full Stack completa** lista para producción, incluyendo:
- [ ] Interfaz de usuario responsiva e interactiva.
- [ ] Backend seguro conectándose a una base de datos relacional/no relacional.
- [ ] Integración con APIs/Servicios Cloud.
- [ ] Sitio desplegado y funcional en un entorno Web en vivo.
